# La Estructura de la Tarjeta "Pro" (Una debajo de la otra)

Hacerlo vertical (un proyecto abajo del otro).
La estructura de cada fila de proyecto debe ser una grilla de dos columnas:

## referencia visual

+------------------------------------------------------------+
|  +--------------------+   AI ENGINEERING PATH (V2.0)       |
|  |                    |   ---------------------------      |
|  |  Imagen/Captura    |   Un reproductor interactivo de    |
|  |  del proyecto      |   diapositivas para registrar mi   |
|  |  (Ancho: 400px)    |   progreso de estudio en IA.       |
|  |                    |                                    |
|  |                    |   [HTML5] [CSS3] [Vanilla JS]      |
|  +--------------------+                                    |
|                           [Ver Demo]  [Ver Código]   |
+------------------------------------------------------------+

**Columna Izquierda (La Imagen):** Una captura prolija y recortada del proyecto funcionando.
**Columna Derecha (La Info):**
**Título:** El nombre oficial del proyecto en mayúsculas.
**Descripción:** 2 o 3 líneas explicando el por qué y la utilidad del proyecto.
**Tecnologías (Badges):** Pequeñas pastillas de texto plano con fondo gris suave (ej: HTML5, CSS3, JS, Markdown) para que el reclutador vea tu stack en 1 segundo.
**Botones de Acción:** Dos enlaces discretos abajo del todo ("Ver Demo" y "Ver Código").
